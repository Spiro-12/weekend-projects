# Weekend Projects

One new fun project every weekend. Small, weird, and actually working.

Live site: https://spiro-12.github.io/weekend-projects/

## Projects

| # | Project | What it is | Demo |
|---|---------|------------|------|
| 01 | [Silent Speech](https://github.com/Spiro-12/silent-speech) | Talk to your Mac without making a sound: the AirPods motion sensor reads your mouthed sentence, your Mac does it. Now its own open source repo. | [live](https://spiro-12.github.io/silent-speech/) |
| 02 | [Fleet Planner](02-fleet-planner/) | A 3D warehouse sim in your browser that tells you which robots to buy, how many, and when they pay for themselves. _(building)_ | [live](https://spiro-12.github.io/weekend-projects/02-fleet-planner/) |
| 03 | [RokidFinder](https://github.com/Spiro-12/rokid-finder) | Rokid Glasses that remember where you put things: tap, ask "where's my phone?", see a photo and hear where you left it. Fully offline, its own open source repo. | [demo + APK](https://github.com/Spiro-12/rokid-finder#rokidfinder) |

## How this repo works

- Each project lives in its own folder: `01-name`, `02-name`, ... (a project that grows up can move to its own repo; its folder then forwards there).
- Every push to `main` deploys all projects to GitHub Pages.
- Copy `_template/` to start a new one.
