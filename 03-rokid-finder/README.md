# RokidFinder lives in its own repo

Rokid Glasses that remember where you put things: tap, ask "where's my phone?", get a photo of where you left it.
Runs fully offline on the glasses.

It is its own open source project: **https://github.com/Spiro-12/rokid-finder** (this folder's page forwards there).

Demo GIF and APK: https://github.com/Spiro-12/rokid-finder#rokidfinder (download: https://github.com/Spiro-12/rokid-finder/releases/latest)
